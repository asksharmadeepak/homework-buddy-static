# Creative brief — Hindi Instagram ad (15–20s)

Goal: parents see the **product in the first 2 seconds**, understand “kids create their own homework,” and tap Install / Learn more.

Format: **9:16 Reels / Stories**, captions always on (many watch muted first).

---

## Hook (0–2 seconds) — non-negotiable

**Visual:** Phone screen showing Homework Buddy create flow OR a printable worksheet filling the frame (Animals / Hindi Swar card). Child’s hand or parent’s hand tapping a theme is ideal.

**On-screen caption (big, center):**
```
बच्चे खुद homework बनाएं
```

**Alt English caption if you prefer bilingual first frame:**
```
Kids create their own homework
```

Do **not** start with logo-only or talking-head without the app/worksheet on screen.

---

## Shot list

| Time | Visual | On-screen text | Audio (Hindi) |
|------|--------|----------------|---------------|
| 0–2s | Worksheet / app theme picker full frame | बच्चे खुद homework बनाएं | “Homework का झगड़ा?” (warm, not shouty) |
| 2–5s | Tap class → activity → theme (speed up OK) | Nursery to Class 3 | “बच्चे theme चुनते हैं…” |
| 5–9s | Preview sheet: story + quiz / Hindi अ tracing | Printable PDF ready | “…और खुद का worksheet बन जाता है।” |
| 9–13s | Printed page + child coloring/writing (or mock) | Calm 10–15 min | “Print करो — बच्चे खुद करके खुश।” |
| 13–18s | App icon + Play badge | Free on Google Play | “Homework Buddy — Google Play पर मुफ़्त।” |
| End card | Logo + “Nursery–Class 3” | Get the free app | Soft music bed under VO |

---

## Primary text (ad copy — paste in Ads Manager)

**Option A (Hindi-first):**
```
बच्चे जब खुद homework बनाते हैं, तो वो करने में भी मज़ा आता है ❤️
Nursery से Class 3 — Reading, Maths, Hindi Fun (स्वर / व्यंजन) और printable PDF।
Free on Google Play.
```

**Option B (English-first):**
```
Don't assign homework — let them invent it.
Kids pick the theme. You print. Done.
Nursery–Class 3 · Hindi Fun · Free on Google Play.
```

**CTA button:** Install now (if Play destination) or Learn more (if `/download`)

---

## Captions / burned-in text rules
- High contrast: white or yellow text with dark outline
- Max ~6 words per line
- Safe margins for Reels UI (keep text in center third)
- End with: `Free · Nursery–Class 3`

---

## What not to say
- “AI worksheet generator” as the lead
- Long feature lists
- “Download our amazing app today!!!” energy

---

## Quick checklist before upload
- [ ] Product visible in first 2 seconds
- [ ] Captions burned in (not only IG auto-captions)
- [ ] Hindi VO clear + soft
- [ ] Ends on Play / free / Nursery–Class 3
- [ ] Same creative used for Play Store destination test (`02-play-store-destination-test.md`)
