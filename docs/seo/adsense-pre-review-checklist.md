# AdSense pre-review checklist

Run before clicking **Request review** in AdSense. Site: easyhomeworkactivity.com.

## Content quality

- [ ] Open 10 random URLs — no identical 4-paragraph block repeated across pages
- [ ] Sr KG, Class 2, one theme, one tool page read as unique parent guides (not templates)
- [ ] Worksheet detail pages: preview + download appear **before** long guide text
- [ ] Homepage reads for parents (class browse, samples, guides) — not SEO manifesto sections
- [ ] `/about` and `/editorial` explain who publishes content

## Technical

- [ ] No AdSense ad units placed yet (wait for approval)
- [ ] `ads.txt` present if required by your AdSense account
- [ ] Mobile: grids and prose readable; PDF downloads work
- [ ] Privacy, Terms, Contact linked from footer

## Search Console (recommended before review)

- [ ] Priority hubs show **Indexed** in URL inspection (nursery, jr-kg, top samples)
- [ ] Sitemap resubmitted after latest content deploy
- [ ] Discovered-not-indexed count trending down (not required for AdSense, but helps)

## Do not

- Request review the same day you deploy major content changes
- Remove sitemap URLs to hide thin pages
- Add `noindex` instead of improving content
- Place ads before approval

## After approval

- Add ad units sparingly — avoid covering download buttons on worksheet pages
- Monitor Core Web Vitals and bounce rate on `/worksheets/*`
